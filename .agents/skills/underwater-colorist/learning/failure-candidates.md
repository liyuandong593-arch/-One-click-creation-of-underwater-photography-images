# Failure Candidates

This file stores candidate failure rules discovered from real user testing.

These are not production failure rules yet.

Only repeatable or high-severity failures should be promoted into the formal failure rule library.

---

## Candidate Template

### Scene

Describe the scene type.

### Mode

### Observed Cases

### Failure Pattern

- Minor

### Evidence

Summarize the supporting test cases.

### Confidence

- High

### Suggested Rule

Describe how similar scenes should be handled next time.
