# Core Grading Rules

## Primary principle

Underwater color grading is color correction and visual enhancement, not image reconstruction.

Priority:

1. Preserve original content
2. Improve subject readability
3. Improve water clarity
4. Preserve underwater depth
5. Recover credible color
6. Apply Natural or Hero styling

## Absolute constraints

Never:

- change composition
- expand the image
- add fish
- add coral
- add marine animals
- add bubbles
- invent light sources
- change fish count
- change fish direction
- alter human anatomy
- alter facial structure
- modify diving equipment
- replace scenery
- fabricate textures

If content preservation conflicts with visual improvement, content preservation wins.

## General grading principles

### Subject first

The primary subject must remain readable.

For people:
- protect face
- protect skin tone
- protect hands and limbs
- protect equipment

For marine life:
- preserve geometry
- preserve direction
- preserve count
- preserve relative positions

### Water clarity

Do not simply increase blue saturation.

First diagnose:
- cyan cast
- green contamination
- gray haze
- excessive blue
- poor midtone separation

Water should look clean and transparent while retaining realistic depth.

### Midtones

Many underwater images fail because midtones are muddy.

Improve midtone readability before aggressively lifting shadows.

### Haze

Underwater images should retain some natural haze.

Do not remove all haze.

Control haze instead of eliminating it.

### Color recovery

Recover warm colors only when the source contains credible information.

Do not fabricate red, orange or skin colors that are no longer present.

Credibility is more important than saturation.

### Local correction

Prefer local adjustment over aggressive global correction when fixing:

- person exposure
- skin tone
- fish visibility
- coral color
- top-water haze
- artificial-light regions

Avoid visible halos.

## Natural mode

Natural means:

- clean
- realistic
- restrained
- transparent
- believable

It should resemble a professionally corrected underwater photograph.

## Hero mode

Hero is built on Natural.

Hero may strengthen:

- subject separation
- visual hierarchy
- midtone clarity
- depth
- local contrast
- cinematic presentation

Hero does not mean:
- more blue
- more saturation
- more sharpening
- fake lighting
- HDR-like effects

Hero means stronger focus, not stronger effects.
